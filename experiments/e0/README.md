# E0 基线结果

运行脚本：

```bash
python -m experiments.e0.e0_baseline \
  --split val \
  --pseudo-test-fraction 0.2 \
  --output experiments/e0/e0_val_results.json
```

脚本不会改写 `data/val.npz`。它按 `target_start_date` 的时间顺序切分官方验证集：最晚的 20% 日期作为模拟测试集，前面的日期作为调试段。

本次切分为：

| 部分 | 样本数 | 预测起始日期 |
| --- | ---: | --- |
| 调试段 | 61,560 | 2023-10-09 至 2024-01-23 |
| 模拟测试集 | 15,390 | 2024-01-24 至 2024-02-27 |

模拟测试集仍然有 `y`，所以它是一个带标签的时间后移评估集，不是最终隐藏测试集。模型选择可以使用调试段，模拟测试集应尽量留到方案确定后再查看。

## 结果

所有预测都在标准化收盘价尺度上进行，预测未来 24 天均使用同一个基准值。

### 调试段

| 基线 | MAE | MSE |
| --- | ---: | ---: |
| 最后值 | 0.244280 | 0.167236 |
| 5 日移动平均 | 0.257807 | 0.177950 |
| 10 日移动平均 | 0.275971 | 0.194759 |
| 20 日移动平均 | 0.310011 | 0.231265 |

### 模拟测试集

| 基线 | MAE | MSE |
| --- | ---: | ---: |
| 最后值 | 0.354286 | 0.330340 |
| 5 日移动平均 | 0.378627 | 0.358666 |
| 10 日移动平均 | 0.392914 | 0.381532 |
| 20 日移动平均 | 0.406871 | 0.414519 |

最后值基线的误差随预测期限变长：

| 评估部分 | 第 1 天 MAE | 第 6 天 MAE | 第 12 天 MAE | 第 24 天 MAE |
| --- | ---: | ---: | ---: | ---: |
| 调试段 | 0.066152 | 0.171203 | 0.249929 | 0.371599 |
| 模拟测试集 | 0.115905 | 0.306501 | 0.350561 | 0.482318 |

因此当前 E0 的主要参照是“复制输入窗口最后一天的标准化 Close”。移动平均在这次验证切分中没有超过最后值，不应作为首选基线。

## 脚本行为

`e0_baseline.py` 会：

1. 从 `HS300Dataset` 读取指定切分的 96 天行情和 24 天标签。
2. 使用每只股票的 `close_mean`、`close_std` 将输入 Close 转换到标签尺度。
3. 计算最后值，以及最近 5、10、20 天标准化 Close 的均值。
4. 按预测起始日期切出最晚一段伪测试集。
5. 输出总体 MAE/MSE 和第 1、6、12、24 天的分期限指标。

例如只评估完整验证集：

```bash
python -m experiments.e0.e0_baseline --pseudo-test-fraction 0
```

调整模拟测试集比例：

```bash
python -m experiments.e0.e0_baseline --pseudo-test-fraction 0.1
```

这个切分按日期进行，而不是随机抽样，因此不会把同一日期的不同股票窗口分到两边，能够更接近未来测试的时间外推场景。
